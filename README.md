# Auction API

A minimal Hello World API built with Kotlin and Ktor.

## Run

```bash
./gradlew run
```

Then request the endpoint:

```bash
curl http://localhost:8080/
```

Expected response:

```text
Hello, World!
```

Set the `PORT` environment variable to use a port other than `8080`.

## Test

```bash
./gradlew test
```
